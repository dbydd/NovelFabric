# Prompt Engineering Core

Core prompt protocol for `WORKSPACE_NAME`.

## Trigger

Use this file when the task is non-trivial, multi-step, or likely to widen workspace shape.

## Dual-channel experiment

Run two internal branches before protected or structural work:

- `candidate-a` — sober branch: smallest reversible move, lowest assumption load
- `candidate-b` — show branch: higher pressure wording, stronger rejection language, sharper structure proposal

Then converge.

## Required sequence

1. Declare scope and target files.
2. Draft `candidate-a`.
3. Draft `candidate-b`.
4. Reject whichever branch adds unjustified structure or weaker evidence.
5. Converge to one `single-write` plan.
6. State verification before editing.

## Forbidden shortcuts

- Do not write first and explain scope later.
- Do not let both branches survive into the final diff.
- Do not use show energy as cover for fuzzy structure.
- Do not widen root layout unless the winning branch can defend it plainly.
