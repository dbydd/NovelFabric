# Commit Message Few-Shot

Use this pattern for protected changes:

`agent: <scope> <short intent>`

## Good scopes

- `harness`
- `tools`
- `ops`
- `artifacts`

## Examples

- `agent: harness tighten tooling boundaries`
- `agent: tools refine reusable script contract`
- `agent: ops clarify rollback procedure`
- `agent: artifacts capture operator audit output`

## Constraints

- keep it single-line
- keep it short
- describe intent, not implementation trivia
