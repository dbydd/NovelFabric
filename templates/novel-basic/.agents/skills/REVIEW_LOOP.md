# REVIEW_LOOP

## Run this before handoff

### Gate ladder

1. `truth gate` — did the winning branch keep canon / inbox / artifact layers separate?
2. `promotion gate` — does any canon change have named intake or editorial basis?
3. `continuity gate` — were adjacent dependencies checked?
4. `artifact gate` — must any derived output be frozen or marked stale?
5. `handoff gate` — can the next editor see what was promoted, rejected, or left unresolved?

### Failure actions

- gate 1 fail → reclassify the file
- gate 2 fail → reject promotion and send it back to inbox or artifact planning
- gate 3 fail → stop the line and reopen neighboring canon
- gate 4 fail → freeze the artifact before shipping canon
- gate 5 fail → rewrite the pack

## Budget rule

If the same gate fails twice, rollback the branch or narrow the subject.
