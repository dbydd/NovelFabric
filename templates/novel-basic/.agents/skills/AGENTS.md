# AGENTS.md

Scope: `templates/novel-basic/.agents/skills/`

## Purpose

- These skill files own narrative operations such as promotion, continuity review, and artifact freeze logic.

## Rules

- Every skill must reinforce truth classification: canon, inbox, or artifact.
- Dual-branch or fanout thinking is allowed during review, but only one truth-classification move may survive into the final write.
- If a skill changes how canon can be promoted, reviewed, or frozen, the rule must be explicit, not implied.

## Stop conditions

- A skill that beautifies prose while blurring truth class is rejected.
- A skill that adds mood but no operational gate does not ship.
