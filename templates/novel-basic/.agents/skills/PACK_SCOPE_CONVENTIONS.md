# PACK_SCOPE_CONVENTIONS

## Phase labels

- `fanout-scan` — inspect canon, inbox, and derived support
- `candidate-a` — canon-safe conservative branch
- `candidate-b` — sharper promotion or repair branch
- `single-write` — one truth-classification move
- `final-gate` — continuity and promotion review

## Narrative scopes

- `canon-basis`
- `inbox-pressure`
- `derived-support`
- `artifact-freeze`

## Rule

If the scope label hides whether the task is changing truth, proposing truth, or only reporting on truth, rename it before writing.
