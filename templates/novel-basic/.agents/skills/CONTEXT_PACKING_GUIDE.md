# CONTEXT_PACKING_GUIDE

## Purpose

Compress workspace evidence without blurring canon, inbox, and artifacts.

## Required fields

- subject and timeframe
- `candidate-a`
- `candidate-b`
- chosen truth-classification move
- rejected branch and reason
- canon basis
- inbox pressure
- derived support
- unresolved contradictions
- stale artifact risk
- next safe action
- rollback point

## Rule

If a pack erases disagreement between canon and inbox, it fails. Packs must preserve conflict until one branch survives review.
