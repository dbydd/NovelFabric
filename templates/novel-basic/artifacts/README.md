# artifacts/

This directory holds derived outputs for `WORKSPACE_NAME`.

## What belongs here

- Audits, context packs, comparison notes, promotion plans, review outputs, branch proposals, and other derived working products.
- Files that help explain or stage changes without becoming accepted truth themselves.

## What does not belong here

- The only copy of a story fact that should be canon.
- Raw intake that should remain in `inbox/`.
- Placeholder reports with no source trail.

## Inspect first

- Start with the canon and inbox files the artifact references.
- Then read the artifact to see what was inferred, compared, or left unresolved.

## Rule

Every serious artifact should make it obvious what was inspected, what was inferred, and what still needs judgment.
