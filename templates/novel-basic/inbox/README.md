# inbox/

This directory is the raw intake surface for `WORKSPACE_NAME`.

## What belongs here

- User notes, imported material, loose scene ideas, contradiction reports, speculative fixes, and promotion candidates.
- Material whose wording, provenance, or certainty still matters.

## What does not belong here

- Accepted canon that should already live in `canon/`.
- Final audits or polished exports that belong in `artifacts/`.
- Silent rewrites that erase where a note came from.

## Inspect first

- First find the canon file this note would affect.
- Then read the inbox item in its original framing.
- Then check whether an artifact already compared or triaged the issue.

## Rule

Using a note is not the same as promoting it. Keep intake recoverable even after downstream changes.
