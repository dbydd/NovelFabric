# AGENTS.md

Scope: `templates/analysis-research/.agents/`

## Purpose

- This subtree governs provenance, protected-note behavior, and evidence-bound synthesis loops.

## Rules

- Protocol here must keep `sources/`, `notes/`, and `artifacts/` sharply separated.
- If a rule changes how support paths, uncertainty, or synthesis are handled, it must strengthen traceability.
- Do not let this subtree become a hidden theory layer that overrides file-backed evidence.

## Stop conditions

- Any protocol that weakens support-path visibility fails the gate.
- A rule that makes polished synthesis outrank evidence is rejected.
