# Commit Message Few-Shot

Use this pattern for protected changes:

`agent: <scope> <short intent>`

## Good scopes

- `harness`
- `notes`
- `artifacts`
- `sources`

## Examples

- `agent: harness tighten provenance rules`
- `agent: notes clarify comparison evidence path`
- `agent: artifacts refine review summary contract`
- `agent: sources document intake provenance expectations`

## Constraints

- keep it single-line
- keep it short
- describe intent, not implementation trivia
