# AGENTS.md

Scope: `templates/analysis-research/.agents/skills/`

## Purpose

- These skill files own intake routing, interpretation discipline, artifact synthesis, and claim-tightening review loops.

## Rules

- Every skill should strengthen source -> note -> artifact transitions.
- Fanout is allowed for comparing candidate framings, but final output must converge to one evidence class and one write surface.
- If a skill hardens claim language, it must also harden support and downgrade logic.

## Stop conditions

- A skill that allows conclusions to outrun support files is rejected.
- New branch logic with no convergence rule does not ship.
