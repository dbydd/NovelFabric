# Review Loop

Run this loop before declaring analysis work complete.

## Loop

1. State the intended change in one sentence.
2. Check whether the result belongs in `sources/`, `notes/`, `artifacts/`, or the harness surface.
3. Inspect the diff for protected files.
4. Verify that important claims still have named support paths.
5. Summarize evidence and any remaining uncertainty.

## Questions

- Did I write a conclusion before naming support files?
- Did I mix raw evidence and interpretation in the same place?
- Is the change easier for the next reviewer to trace and re-check?
- If a protected file changed, is the intent visible in the diff?
