# Global Prompt Skill Stack

Use global prompt skills for generic prompting problems. Use local files here for provenance, placement, and evidence review.

## Available global skills

- `prompt-engineering-patterns` — prompt structure, few-shot design, and framing quality
- `ai-prompt-engineering-safety-review` — safety and robustness review for prompts
- `boost-prompt` — refining a vague request before writing analysis text

## Usage order

1. Read `AGENTS.md`, `SOUL.md`, and `template.json`.
2. Use a global prompt skill only for the generic prompting issue.
3. Return here for `sources/` vs `notes/` vs `artifacts/` placement, protected note rules, and completion evidence.

## Local-vs-global rule

- Global skills solve the broad prompt-design problem.
- Local files here decide what counts as evidence, interpretation, and derived output in this workspace.
- Do not copy a large generic framework into this template unless it materially changes local research behavior.
