# Artifacts

Use `artifacts/` for derived outputs in this workspace.

## Belongs here

- reviewable reports, comparison outputs, audit summaries, and generated deliverables
- exports whose purpose is to present or hand off conclusions already supported elsewhere
- derived views that can point back to notes or source files

## Does not belong here

- the only copy of raw evidence
- working interpretation that still belongs in `notes/`
- polished claims that cannot name supporting files

## Inspect first

Before writing here, confirm the supporting `sources/` or `notes/` files already exist. If the output is still exploratory rather than presentable, keep it in `notes/` instead.
