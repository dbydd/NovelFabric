# Notes

Use `notes/` for working interpretation built from evidence.

## Belongs here

- reading notes and structured summaries tied to named source files
- comparisons, extraction tables, working judgments, and open questions
- intermediate reasoning that should stay reviewable before final export

## Does not belong here

- raw source copies with no interpretation
- final polished deliverables that belong in `artifacts/`
- unsupported claims with no named support path

## Inspect first

Before writing here, inspect the supporting `sources/` files and keep their paths recoverable in the note. If the text is a final deliverable rather than a working note, it belongs in `artifacts/`.
