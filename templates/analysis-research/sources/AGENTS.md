# AGENTS.md

Scope: `templates/analysis-research/sources/`

## Purpose

- This subtree stores imported or copied evidence with provenance intact.

## Rules

- Preserve source identity, wording fidelity where relevant, and origin metadata.
- Keep commentary out unless it is strictly metadata needed for traceability.
- If interpretation is needed, move it into `notes/` instead of laundering it into the source.

## Stop conditions

- Silent cleanup that changes meaning fails review.
- A source file that becomes interpretive prose must be split or reverted.
